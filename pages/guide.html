Getting Started

はじめに — このサイトの使い方

大会の対戦表・選手の戦績・ランキングは、ログインなしで誰でも見られます。 大会に参加するときだけ、ログインと選手登録が必要です。

0. アカウントの作り方 1. 各ページの説明 2. 大会エントリー方法 3. ランキングの仕組み 4. 大会を開きたい人へ

0アカウントの作り方

見るだけならログインは要りません。大会に参加するときに必要になります。 持っているGoogleかDiscordのアカウントで入れるので、新しくパスワードを作る必要はありません。

  1. 1ログインする

    画面右上の「ログイン」を押すと、選ぶ画面が出ます。 GoogleかDiscordの、どちらか持っているほうを押してください。 いつも使っているアカウントでそのまま入れます。

    初めてでも、アカウントを新しく作る手続きはありません。 パスワードをこのサイトが預かることもありません。

  2. 2選手として登録する

    初回だけ選手登録の画面が出ます。 プレイヤー名（大会や対戦表に出る名前）を決めて登録すると完了です。

    「任意」と付いている欄は空のままでも構いません。あとからいつでも足せます。

    プレイヤー名は、対戦表だけでなくランキングの一覧・順位発表の動画・配信の画面にも そのまま出ます。わいせつな表現・差別的な表現・他人を指す名前など、 公の場に出せない名前は使えません。 不適切と判断した場合、ランキングへの掲載や配信台での紹介を見送ることがあります。 迷ったら、配信でそのまま読み上げられても困らない名前にしてください。

    • プレイヤー名 — 対戦表・ランキング・配信に出る名前
    • ゲームアカウントID — フレンド申請に使う番号
    • 使用キャラクター — カンマ区切りで複数書けます
    • X / YouTube・自己紹介 — 任意

  3. 3プロフィールを整える

    マイページには他の人から見えるあなたのプロフィールがそのまま出ます。 直したいときは、名前の横の鉛筆アイコンを押すと編集画面に切り替わります。 保存すると、また見え方の確認に戻ります。

    アイコンを設定しておくと、対戦表やランキングで見つけてもらいやすくなります。 プレイヤー名を変えても戦績は消えません（前の名前は「過去名」として残ります）。

1このサイトの各ページ

画面の移動は、左上のメニュー（☰）からです。

  • ホーム

    サイトの紹介と、運営からの最新のお知らせ。まずここを見れば、いま何が動いているか分かります。

  • お知らせ

    運営からのお知らせの一覧です。新しい順に並びます。

  • 大会

    大会の一覧です。募集中・進行中・終了のタブで切り替えます。参加は募集中タブから。大会を開くとルール・参加者・対戦表が見られます。

  • ランキング・選手

    公開中のランキング。上の検索欄に名前を入れると、その選手のページを探せます。

  • エントリー状況

    自分がエントリー・出場した大会のまとめです。自分の大会へはここからが早道です。

  • マイページ

    ログイン・選手登録と、自分のプロフィール。鉛筆アイコンから編集します。

  • お問い合わせ（X）

    運営への連絡先です。分からないことや、大会を開きたいときはこちらへ。

2大会エントリー方法

エントリー → 対戦 → 結果の報告、という流れです。 先に0. アカウントの作り方を済ませておいてください。

  1. 1大会にエントリー

    「大会」の募集中タブから大会を開き、ルールを確認して「エントリーする」を押すだけです。 募集中の間は何度でも取り消せます。 締め切られると、それまでの戦績をもとに対戦表（トーナメント表）が作られます。

  2. 2対戦表で自分を見つける

    大会が始まったら対戦表を開きます。色の付いた行があなたです。 対戦カードの右端にある鉛筆アイコンを押すと、その対戦の画面 （ルームコード・チャット・ゲームカウント）が開きます。 選手名を押すと、その選手のプロフィールが見られます。

  3. 3開始の合図を待って対戦

    対戦を始めてよいかは、対戦画面のいちばん上で分かります。 運営がその回戦を開始すると、「開始待ち」が「試合開始」に変わります。 画面を開いたまま待っていて構いません（変わった瞬間に切り替わります）。

    その下にルームコード欄があります。 配信される試合では運営が先に記入していることもあります。 空いていれば、部屋を建てた側がコードを記入してください。 待ち合わせの連絡は同じ画面のチャットでできます。

  4. 4ゲームカウントを入力

    試合が終わったら、対戦画面の「ゲームカウント」タブで結果を入力します。 入力できるのは勝った側・負けた側のどちらでもかまいません。 入れた時点で確定し、対戦表が自動で進みます（相手の承認は要りません）。 入力後の訂正は運営しかできないので、数字を確かめてから押してください。 間違えたときや結果が食い違うときは、次の「困ったときは」を読んでください。

    どちらかが入力 → その場で確定 → 対戦表が進む

  5. 5困ったときは

    相手と連絡がつかない・入力したカウントを間違えた・結果が食い違うなど、 困ったときは対戦画面の 「運営に報告」を押してください。運営の画面にすぐ印が付きます。 確定した結果を直せるのは運営だけなので、間違いに気づいたらそのままにせず、 必ずここから連絡してください。

3ランキングの仕組み

すべての大会がランキングに入るわけではありません。条件を満たした大会の試合だけがスコアになります。

ランキングに入る大会の条件

次の3つともを満たす大会が対象です。1つでも欠けると、 その大会の試合はスコアに影響しません（戦歴には残ります）。

  • 参加16人以上であること
  • 対戦方法が1v1 または リレーであること（2v2・その他は対象外）
  • 主催者がランキングへの反映を外していないこと （エキシビションや練習会は、条件を満たしていても外されていることがあります）

対象かどうかは、各大会の詳細ページに印で出ています。エントリーする前に確認できます。

スコアと順位の見かた

スコアは相手の強さで重み付けして計算します。強い選手に勝つほど大きく上がり、 格下に負けるほど大きく下がります。大会の規模（参加人数）も重みになります。

順位の右にある▲▼の印は、前回公開したランキングと比べた動きです。 NEW は今回から入った選手です。

ランキングは自動では変わりません。運営が集計して公開したときに切り替わります。 集計期間はページ上部に出ています。

4大会を開きたい人へ

大会を作れるのは運営権限を持つアカウントだけです。まずは連絡から。

  1. 1運営に連絡して権限をもらう

    お問い合わせ（X） から、開きたい大会の内容とこのサイトでのプレイヤー名を伝えてください。 先に0. アカウントの作り方を済ませておくと、 そのアカウントに権限を付けられます。

    権限が付くと、メニューに「大会作成」が現れます。

  2. 2大会を作る

    「大会作成」で、大会名・開催日・対戦方法・定員・ルール・ 配信元のURL・画像を入力します。対戦方法は ランキングの対象かどうかを決めるので、必ず実態に合わせてください。

    参加者の集め方は2通りです。

    • エントリーを募集する — 選手が自分で参加登録する（通常はこちら）
    • 運営が参加者を直接選ぶ — その場で対戦表まで作る

  3. 3締め切って対戦表を作る

    集まったら「締め切ってブラケット生成」を押します。 それまでの戦績からシードが決まり、対戦表が自動で作られます。

    自動の組み合わせを直したいときは、対戦表ページの 「組み合わせを調整する」から、選手を2人ずつ選んで入れ替えられます （回戦を開始する前まで）。

  4. 4配信台を決めて回戦を開始する

    回戦ごとに、配信に乗せる試合（配信台）を選んでから 「開始」を押します。開始して初めて、選手はゲームカウントを報告できるようになります。

    配信台の試合は、開始前にルームコードを先に記入しておけます。 選手は開始と同時にコードを確認できます。

  5. 5結果を確認して大会を確定する

    選手どうしで確定した結果は自動で進みます。運営は対戦カードの鉛筆から その場で結果を入れることも、不戦勝で確定することもできます。

    すべての対戦が終わると「結果を確定する」が出ます。押すと最終順位が決まり、 各選手の戦歴に反映されます。

  6. 6ランキングを公開する

    「ランキング・選手」ページの「ランキングを作成する」から、 集計する期間をカレンダーで指定します。その場で結果を確かめられます （この時点ではまだ閲覧者には見えません）。

    「このランキングを公開する」を押すと切り替わります。

  7. 7もめごとへの対応

    選手から「運営に報告」が届くと、大会のカードと対戦表に印が出ます。 対戦のチャットを開いて内容を確認し、「対応済みにする」を押すと印が消えます。
