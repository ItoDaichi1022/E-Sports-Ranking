はじめに — このサイトの使い方

大会の対戦表・選手の戦績・ランキングは、ログインなしで誰でも見られます。 大会に参加するときだけ、ログインと選手登録が必要です。

0アカウントの作り方

見るだけならログインは要りません。大会に参加するときに必要になります。 持っているGoogleかDiscordのアカウントで入れるので、新しくパスワードを作る必要はありません。

  1. 1ログインする

    画面右上の「ログイン」を押すと、選ぶ画面が出ます。 GoogleかDiscordの、どちらか持っているほうを押してください。 いつも使っているアカウントでそのまま入れます。

    初めてでも、アカウントを新しく作る手続きはありません。 パスワードをこのサイトが預かることもありません。

  2. 2選手として登録する

    初回だけ選手登録の画面が出ます。 表示名（大会や対戦表に出る名前）を決めて登録すると完了です。

    「任意」と付いている欄は空のままでも構いません。あとからいつでも足せます。

    • 表示名 — 対戦表・ランキングに出る名前
    • ゲームアカウントID — フレンド申請に使う番号
    • 使用キャラクター — カンマ区切りで複数書けます
    • X / YouTube・自己紹介 — 任意

  3. 3プロフィールを整える

    マイページには他の人から見えるあなたのプロフィールがそのまま出ます。 直したいときは、名前の横の鉛筆アイコンを押すと編集画面に切り替わります。 保存すると、また見え方の確認に戻ります。

    アイコンを設定しておくと、対戦表やランキングで見つけてもらいやすくなります。 表示名を変えても戦績は消えません（前の名前は「過去名」として残ります）。

2大会エントリー方法

エントリー → 対戦 → 結果の報告、という流れです。 先に0. アカウントの作り方を済ませておいてください。

  1. 1大会にエントリー

    「募集中の大会」から大会を開き、ルールを確認して「エントリーする」を押すだけです。 募集中の間は何度でも取り消せます。 締め切られると、それまでの戦績をもとに対戦表（トーナメント表）が作られます。

  2. 2対戦表で自分を見つける

    大会が始まったら対戦表を開きます。色の付いた行があなたです。 対戦カードの右端にある鉛筆アイコンを押すと、その対戦の画面 （ルームコード・チャット・ゲームカウント）が開きます。 選手名を押すと、その選手のプロフィールが見られます。

  3. 3ルームコードを確認して対戦

    対戦の画面を開くと、いちばん上にルームコード欄があります。 配信される試合では運営が先に記入していることもあります。 空いていれば、部屋を建てた側がコードを記入してください。 待ち合わせの連絡は同じ画面のチャットでできます。

  4. 4ゲームカウントを報告

    試合が終わったら、対戦画面の「ゲームカウント」タブで結果を入力します。 相手が承認すると確定し、対戦表が自動で進みます。 数字が違うと思ったら、承認せずに自分のカウントを出し直せば上書きされます。

    自分が報告 → 相手が承認 → 対戦表が進む

  5. 5困ったときは

    相手と連絡がつかない・結果が食い違うなど、もめたときは対戦画面の 「運営に報告」を押してください。運営の画面にすぐ印が付きます。

3ランキングの仕組み

すべての大会がランキングに入るわけではありません。条件を満たした大会の試合だけがスコアになります。

ランキングに入る大会の条件

次の2つともを満たす大会が対象です。どちらか一方でも欠けると、 その大会の試合はスコアに影響しません（戦歴には残ります）。

  • 参加24人以上であること
  • 対戦方法が1v1 または リレーであること（2v2・その他は対象外）

対象かどうかは、各大会の詳細ページに印で出ています。エントリーする前に確認できます。

スコアと順位の見かた

スコアは相手の強さで重み付けして計算します。強い選手に勝つほど大きく上がり、 格下に負けるほど大きく下がります。大会の規模（参加人数）も重みになります。

順位の右にある▲▼の印は、前回公開したランキングと比べた動きです。 NEW は今回から入った選手です。

ランキングは自動では変わりません。運営が集計して公開したときに切り替わります。 集計期間はページ上部に出ています。

4大会を開きたい人へ

大会を作れるのは運営権限を持つアカウントだけです。まずは連絡から。

  1. 1運営に連絡して権限をもらう

    お問い合わせ（X） から、開きたい大会の内容とこのサイトでの表示名を伝えてください。 先に0. アカウントの作り方を済ませておくと、 そのアカウントに権限を付けられます。

    権限が付くと、メニューに「大会作成」が現れます。

  2. 2大会を作る

    「大会作成」で、大会名・開催日・対戦方法・定員・ルール・ 配信元のURL・画像を入力します。対戦方法は ランキングの対象かどうかを決めるので、必ず実態に合わせてください。

    参加者の集め方は2通りです。

    • エントリーを募集する — 選手が自分で参加登録する（通常はこちら）
    • 運営が参加者を直接選ぶ — その場で対戦表まで作る

  3. 3締め切って対戦表を作る

    集まったら「締め切ってブラケット生成」を押します。 それまでの戦績からシードが決まり、対戦表が自動で作られます。

    自動の組み合わせを直したいときは、対戦表ページの 「組み合わせを調整する」から、選手を2人ずつ選んで入れ替えられます （回戦を開始する前まで）。

  4. 4配信台を決めて回戦を開始する

    回戦ごとに、配信に乗せる試合（配信台）を選んでから 「開始」を押します。開始して初めて、選手はゲームカウントを報告できるようになります。

    配信台の試合は、開始前にルームコードを先に記入しておけます。 選手は開始と同時にコードを確認できます。

  5. 5結果を確認して大会を確定する

    選手どうしで確定した結果は自動で進みます。運営は対戦カードの鉛筆から その場で結果を入れることも、不戦勝で確定することもできます。

    すべての対戦が終わると「結果を確定する」が出ます。押すと最終順位が決まり、 各選手の戦歴に反映されます。

  6. 6ランキングを公開する

    「ランキング・選手」ページの「ランキングを作成する」から、 集計する期間をカレンダーで指定します。その場で結果を確かめられます （この時点ではまだ閲覧者には見えません）。

    発表用の画像を書き出してから、「このランキングを公開する」を押すと切り替わります。

  7. 7もめごとへの対応

    選手から「運営に報告」が届くと、大会のカードと対戦表に印が出ます。 対戦のチャットを開いて内容を確認し、「対応済みにする」を押すと印が消えます。

    2. 取得する情報

    本サイトは、次の情報を取得します。

    1. ログインに関する情報
      GoogleまたはDiscordでログインしたときに、これらのサービスから受け取るメールアドレスとアカウント識別子。 パスワードは受け取らず、本サイトには保存されません。
    2. 選手登録・プロフィールの情報
      表示名、過去の表示名、ゲームアカウントID、使用キャラクター、自己紹介、アイコン画像、XおよびYouTubeのアカウント。 表示名以外の入力は任意です。
    3. 大会の記録
      大会へのエントリー状況、チーム編成、対戦結果、対戦相手とのチャットの内容、対戦部屋のルームコード、運営者への報告内容。
    4. アクセスに関する情報
      本サイトの配信およびデータの保管を担う事業者が自動的に記録する、IPアドレス、ブラウザの種類、アクセス日時などの情報。 運営者はこれらを個人を特定する目的では利用しません。

    本サイトは、広告配信やアクセス解析のためのツールを利用しておらず、行動履歴を追跡するCookieも使用していません。

    3. 利用目的

    取得した情報は、次の目的でのみ利用します。

    1. 本サイトへのログインおよび本人確認のため
    2. 大会のエントリー受付、対戦表の作成、対戦結果の記録のため
    3. 選手ページ、対戦表、ランキングの表示のため
    4. 対戦相手どうしの連絡（対戦チャット、ルームコードの共有）のため
    5. 不正な報告、規約違反、なりすましへの対応のため
    6. お問い合わせへの回答のため

    4. 情報が表示される範囲

    お預かりした情報のうち、他の人から見えるものと見えないものは次のとおりです。

    情報見られる範囲
    表示名・過去の表示名・アイコン画像・自己紹介・使用キャラクター・ゲームアカウントID・SNSのリンク ログインしていない方を含む、誰でも
    大会の参加状況・対戦結果・戦績・ランキングの順位 ログインしていない方を含む、誰でも
    対戦チャットの内容・ルームコード その試合の対戦者本人と、運営権限を持つ者のみ
    運営者への報告内容 報告した本人と、運営権限を持つ者のみ
    メールアドレス 本人のみ（マイページに表示されます）

    プロフィールと戦績は公開されることを前提とした情報です。知られたくない情報は入力しないでください。 ゲームアカウントIDと自己紹介は、いつでもマイページから削除できます。
